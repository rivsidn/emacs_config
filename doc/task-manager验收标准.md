# task-manager 验收标准

本文档用于记录 task-manager 功能的验收标准，与 [task-manager需求说明](task-manager需求说明.md) 对应。

## 基础流程

- 创建工作任务后，应在 `工作任务` 节点下生成 `TODO` 任务，并自动填写创建时间、优先级和用户选择的属性。
- 创建工作想法后，应在 `工作想法` 节点下生成 `TODO` 想法，并自动填写创建时间和优先级。
- 开始任务或想法后，应停止其它计时、切换为 `DOING`、创建详情目录和 `.org` 详情文件，并打开详情文件。
- 暂停任务或想法后，应停止当前计时并切换为 `PAUSED`。
- 结束任务或想法后，应停止当前计时、切换为 `DONE`，并跳转到总结区域。

## 数据与文件

- 外部列表文件缺失时，创建流程仍可通过手动输入继续完成。
- 详情目录或详情文件已经存在时，不重复创建，也不覆盖用户已有内容。
